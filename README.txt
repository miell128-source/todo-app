TO DO PWA - 탭 기능 추가 버전

기능
- + 버튼으로 새 TO DO 탭을 만들고 이름을 직접 입력합니다.
- 새 탭은 빈 목록으로 시작하며, 탭마다 할 일이 따로 저장됩니다.
- 탭 이름을 두 번 누르면 이름을 바꿀 수 있습니다.
- 기존 단일 목록의 할 일은 첫 번째 'TO DO' 탭으로 자동 이전됩니다.
- 각 기기 브라우저에 저장되며, 기기 간 자동 동기화는 지원하지 않습니다.

업데이트 방법
1. 압축을 풀고 안의 파일 4개(index.html, manifest.webmanifest, sw.js, icon.svg)를 기존 GitHub 저장소에 업로드합니다.
2. 기존 파일과 같은 이름이므로 덮어쓰기를 선택하고 Commit changes 합니다.
3. GitHub Pages 배포가 끝난 뒤 휴대폰에서 기존 TO DO 앱을 닫았다가 다시 엽니다.
4. 새 탭 + 버튼이 보이는지 확인합니다. 바로 바뀌지 않으면 Chrome에서 페이지를 새로고침하거나 잠시 기다렸다 다시 엽니다.

주의
- 기존 할 일은 새 버전 첫 실행 시 첫 번째 'TO DO' 탭으로 옮겨집니다.
- 이 앱은 현재 기기의 브라우저 저장 공간을 사용합니다. 사이트 데이터/앱 데이터를 지우면 내용이 사라질 수 있습니다.
- PC와 휴대폰 사이 자동 동기화는 별도 클라우드 기능이 필요합니다.
